# Mercado em Conexão 2027 · 18ª Edição

Landing Page de alta conversão para o evento de lançamento da 18ª edição da **Mercado em Conexão (UFMG Hub / Escola de Engenharia da UFMG)**.

Desenvolvida para atender executivos e tomadores de decisão corporativa que acessam via QR Code impresso no folder do evento.

## Funcionalidades
- Hero institucional com imagem da feira e tratamento fosco (frosted glass).
- Impacto auditado (4.715 alunos presenciais, 47% dos alunos de engenharia da UFMG, 34 marcas líderes, 970 mil views orgânicas).
- Apresentação executiva das 4 cotas de patrocínio (Bronze, Prata, Ouro e Diamante).
- Carrossel swipe interativo otimizado para dispositivos móveis.
- Integração direta com canal de atendimento WhatsApp corporativo.
